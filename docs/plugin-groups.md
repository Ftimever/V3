# 插件组

插件组是部署和版本管理单元，不是单一插件对象。组内成员保留独立实例 ID、资源作用域、权限、日志与运行状态。

## 三文件模型

- `plugin-group.json`：组身份、成员请求、运行选择、权限策略与服务绑定。
- `group.lock`：实际版本、来源、完整依赖图、完整性摘要和解析结果。
- `group.config.json`：实例配置与声明启停意图。

实时状态不写回可提交 Git 的配置；未来由状态存储单独维护。密钥通过引用注入，不写入 manifest、锁文件或普通配置。

第一阶段只实现 group manifest Schema 和类型。安装、版本解析、锁文件、存储、升级与回滚都尚未实现。

## 升级设计

准备新版本并验证后，停止旧组、启动新组并等待 required 成员就绪。失败时停止新组、恢复旧锁定信息和配置，并重新启动旧组。第一版不实现新旧并行切换。

回滚不能撤销已经发送的外部请求、消息或数据库不可逆迁移。未来部署 API 必须区分“恢复旧部署”与“恢复所有业务数据”，并允许报告回滚失败、人工介入和迁移不兼容。

共享实例、跨组依赖和组外服务替换尚未开放；实现前必须明确组所有权和停用影响，不能默认为整组原子操作。
